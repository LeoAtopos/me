# 解析占有，精致自省

我是华人。我是喜欢你的。这两句话的“是”字的意思一样吗？

我有权利，我有技术。这两句话里的“有”是一个意思吗？

上次把“玩游戏”分成了好几个不同的档位，这次我又想解析一下“占有”。因为我发现很多时候，人们会真以为占有某物是天然的，自成立的。

**一、共识占有**

台湾省里有不少人老说民族自决，自己认为自己是独立国家了，就应该是独立国家了。这就和我在地上画个圈，声称自己独立建国一样荒谬。

一个人占有土地，资产，金钱，其实都是一种共识性占有，是大家按照某种共识承认了你的占有，你才占有的。只要没人承认，或者多数人不承认，你的占有就会被剥夺。

人在社会关系中的绝大多数对物和权的占有，都是这种。只有在秩序存在并支持你的占有主张的时候，你才是真的占有。

当秩序不存在了，你的占有权就没了。例如碰上抢劫和战乱。

当多数人不承认你的占有了，你的占有也没了。例如法院判决后的抚养权。

所以，对这样的占有，最重要的是保持社会秩序，以及你占有这个东西的集体共识，制度确认。不能幻想对某种天理来保障占有。

**二、博弈占有**

有个新闻，说某省一个柜台办事的公务员，只是负责资料打印的，都能受贿几百万。人们惊讶于这点小角色也能大贪啊。

原来他负责给上头打印外面公司投递来的招标文件，事务产生权力，他就能决定先打印谁家的文件，什么时候送到。只是为了怕他坏事儿，竞标公司都要给他打点送钱。

这就是在没有秩序共识的地方，谁能在博弈中取得优势，谁就能占有。

战乱与大饥荒年代，你家的那片玉米地的收成到底是谁的，那就是当时当地的斗争博弈的胜出者占有了。

通过博弈完成了排他的占有，其实是相当硬的占有，但也是相当脆的占有。只要在下次博弈中落败，占有就不存在了。

市场本事一个博弈场，超额利润赚大钱，通常都是属于这种博弈大胜的结果，是在非共识中取得的。所以起落无常，因为下次博弈可能就全输了。

**三、内化占有**

老一辈总说，学好数理化，走遍天下都不怕。知识技能，尤其是默会知识的占有，就属于这种内化占有。

首先这种占有并不排他，不是你有了，别人就不能有了。此次，这种占有甚至无法被剥夺，一旦占有，除非自己放弃，就不可能被拿走。

所以，这种占有有时候是不稀缺的，例如识字，旅游体验。有的则非常稀缺，各种专精领域的最前沿技术和能力。

内化占有是获得感和获得后的安全感最强的，一无所有的时候，去找一点内化占有物，是简单而安心的。因而有人通过探索和学习环节焦虑。

或者说，在某件事情上只有你能做，别人因能力不足而都做不了的时候，这个事儿及相关的权益也都是被你占有的。

**四、私交占有**

我有个儿子，说的就是这种占有。当A说这事儿可以找B来做，B获得机会的权力来自于B在A心里占有的位置。这也是私交占有。

当然最常见的私交占有，就是占有某个亲友的时间。

如果说人的本质是社会关系的总和，那私交占有真的是很多人的本质的主要决定因素。

儒家很早就看清这点，并重视这点，从而带来了忠孝仁义，其实都是扩大私交占有。

现代社会说是一个平民的平等社会，但人们既不满足于这样的原子化社会，更发觉真正有力量的组织都是私交升级后的产物。

有时候我觉得，一个人的私交才是一个人真实的社会存在，而不是公民，市民，成年人，领导或员工这样的虚拟头衔。

**五、天然占有**

不要以为四肢身体是天然占有，其实那是共识占有。不然法院无法剥夺一个人的生命。

真正的天然占有只有每个人自己的记忆。这不需要任何人承认，也不需要和任何人博弈，甚至不用学习内化，一个人天然就占有他经历的记忆，只有他自己忘却，没有他人的剥夺。

**总结**

为什么要区分这些占有的性质呢？除了哲思有趣之外，更想让自己明确自己在追求的到底是什么样的一种存在。
